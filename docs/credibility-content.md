# Credibility and publication policy

This release establishes IOA's credibility through positioning, methodology, capabilities and technical depth. Selected engagements and implementation details are confidential. Public copy describes system types and delivery methods without revealing protected client or project information.

## Current release

- Omit individual practitioner profiles unless all statements use verified public information and publication is approved.
- Do not publish client identities, testimonials, logos, statistics, project details, demonstrations or case studies without explicit authorization.
- Do not create fake, inferred, illustrative or placeholder client evidence.
- Describe operational architecture, workflow engineering, systems integration, internal tools, automation, governance, data architecture and decision systems at a capability level.
- Frame expected benefits as design objectives, not verified outcomes from client work.
- Keep protected project status, completion figures and implementation specifics out of website content and source files.

## Adding verified case studies later

`EnterpriseSystems` accepts optional `PublishedCaseStudy` records and displays them only when `publicationApproved` is true. No records are currently supplied. The component reuses the existing responsive system-card layout; adding approved content does not require redesigning the page.

Before supplying a record, verify:

- Every statement is factual and supported by approved evidence.
- Any context and implementation description can safely be disclosed, including when combined with other public information.
- IOA's actual responsibility is described accurately.
- Any optional outcomes are verified; any numerical result includes an approved basis of measurement.
- Written publication authorization covers the complete public account and any identifying or technical details.

Do not add draft or placeholder records to production source. Keep unpublished material outside the public repository and deployment. If authorization is withdrawn, remove the affected record. With no approved records, the site shows only capabilities and the confidentiality statement.
